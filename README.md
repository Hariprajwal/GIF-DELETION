# 🗑️ GIF-Deletion: Media Pipeline Cleanup Utility

**GIF-Deletion** is a high-speed utility script designed to manage local storage for bulk media projects. When running automated pipelines (like a YouTube-to-GIF converter), local directories can quickly fill with gigabytes of data. This tool automates the cleanup process.

## 🚀 The Use Case
Perfect for developers and content creators who:
* Generate hundreds of GIFs daily and need a one-click purge.
* Want to clear specific output folders without manual selection.
* Are building automated "Produce -> Upload -> Delete" workflows.

## ✨ Features
* **Bulk Execution:** Clears entire directories in milliseconds.
* **Targeted Deletion:** Focuses specifically on GIF extensions to protect other project files.
* **Pipeline Integration:** Easily callable as a sub-process in larger automation chains.

## 🛠 Tech Stack
* **Language:** Python 3.12
* **Modules:** `os`, `shutil`, `glob`

## 📦 Integration Example
You can trigger this script at the end of your [GIF-Automator](https://github.com/Hariprajwal/GIF-Automator) run to ensure your server/PC stays clean.
